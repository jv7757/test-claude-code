# 📚 AI多智能体小说创作系统（多章节版）

基于 **LangGraph** 和 **Gradio** 的多智能体协作小说创作应用。本系统支持多章节创作，已完成章节作为知识库供后续创作参考，并通过智能审核循环机制确保每章质量。

## ✨ 特性

- 🎬 **策划者智能体**：创建包含多个章节的详细大纲（5-8章）
- ✍️ **作家智能体**：逐章创作并润色，参考已完成章节（知识库）
- 🎭 **评论家智能体**：严格评审每章质量并决定是否通过
- 📖 **多章节支持**：支持创建和管理多个章节，灵活的创作顺序
- 🔄 **智能审核循环**：每章独立审核，不通过时作家根据反馈修改（最多5次）
- 📚 **章节知识库**：后续章节自动参考已完成章节，确保故事连贯性
- 📊 **实时进度显示**：章节目录侧边栏实时显示创作进度
- 🌐 **友好的Web界面**：基于Gradio构建的直观三栏布局

## 🏗️ 系统架构

本系统采用 LangGraph 构建多智能体工作流，支持多章节创作和条件循环：

```
┌─────────────── 第一步：创建大纲 ───────────────┐
│                                               │
│   用户输入主题                                 │
│       ↓                                       │
│   策划者生成多章节大纲（5-8章）                │
│       ↓                                       │
│   解析并保存章节列表                           │
│                                               │
└───────────────────────────────────────────────┘

┌─────────────── 第二步：逐章创作 ───────────────┐
│                                               │
│   用户选择章节号（可任意顺序）                 │
│       ↓                                       │
│   作家创作该章                                 │
│       ├─ 参考：总体大纲                       │
│       ├─ 参考：该章概要                       │
│       └─ 参考：已完成章节（知识库）           │
│       ↓                                       │
│   评论家评审该章                               │
│       ↓                                       │
│   ┌──── 通过审核？────┐                       │
│   │                  │                       │
│  是                 否                        │
│   │                  │                       │
│   ↓                  ↓                        │
│  保存章节     作家修改（最多5次）               │
│               │                               │
│               └──→ 返回评论家                  │
│                                               │
└───────────────────────────────────────────────┘

┌─────────────── 第三步：导出小说 ───────────────┐
│                                               │
│   导出所有已完成章节                           │
│       ↓                                       │
│   生成完整小说文本                             │
│                                               │
└───────────────────────────────────────────────┘
```

### 知识库机制

当创作第N章时，系统会自动提取前面所有已完成章节（第1至N-1章）的内容作为上下文知识库，供作家参考，确保：

- **人物一致性**：角色性格、外貌、背景保持一致
- **情节连贯性**：故事线索、时间线、因果关系合理
- **风格统一性**：语言风格、叙事节奏、氛围保持统一

- Python 3.8+
- OpenAI API Key

### 2. 安装依赖

```bash

```

### 3. 配置环境变量

复制 `.env.example` 文件并重命名为 `.env`：

```bash

```

编辑 `.env` 文件，填入你的 OpenAI API Key：

```
OPENAI_API_KEY=your_openai_api_key_here
```

### 4. 启动应用

```bash
python app.py
```

应用将在 `http://localhost:7860` 启动。

## 📖 使用说明

### 步骤1：创建大纲

1. 在左侧面板输入你的 OpenAI API Key
2. 选择合适的模型（推荐 `gpt-4o-mini` 或 `gpt-4`）
3. 在"小说主题"文本框中描述你的小说
4. 点击"创建大纲"按钮

系统将生成包含5-8个章节的详细大纲，并在右侧显示章节目录。

### 步骤2：逐章创作

1. 在右侧章节目录中查看所有章节
2. 在左侧"选择要创作的章节号"输入框输入章节号（1-N）
3. 点击"创作该章节"按钮
4. 等待AI创作完成（2-5分钟）

**注意**：
- 可以按任意顺序创作章节
- 后续章节会自动参考已完成的前面章节
- 每章独立审核，最多修改5次

### 步骤3：查看结果

在中间内容区的标签页中查看：

- 📋 **总体大纲**：查看完整的多章节规划
- 📊 **创作状态**：当前章节的创作信息（修改次数、审核结果）
- ✨ **当前章节**：刚完成的章节内容
- 💬 **当前评审**：最新的评审反馈
- 📜 **评审历史**：所有评审记录
- 📖 **完整小说**：导出所有已完成章节

### 步骤4：导出小说

所有章节创作完成后，点击"导出完整小说"按钮，系统会按章节顺序生成完整的小说文本。

## 🎯 核心功能

### NovelWritingAgents 类

多智能体系统的核心类，包含：

- `_planner_agent()` - 策划者智能体（生成多章节大纲）
- `_parse_chapter_outlines()` - 解析章节信息
- `_writer_agent()` - 作家智能体（创作章节，参考知识库）
- `_get_previous_chapters_context()` - 获取已完成章节作为知识库
- `_critic_agent()` - 评论家智能体（评审章节质量）
- `_should_continue()` - 条件判断函数（决定循环或结束）
- `create_chapter()` - 创作单个章节
- `get_chapter_list()` - 获取章节列表

### 章节状态

每个章节包含以下状态：

- **pending** (⏸️ 待创作): 尚未开始创作
- **in_progress** (▶️ 进行中): 正在创作
- **completed** (✅ 已完成): 创作完成并通过审核

### 审核标准

评论家的评分标准：

- **8-10分**：优秀，通过审核 ✅
- **6-7分**：良好，可以通过 ✅
- **4-5分**：一般，需要改进 ❌
- **1-3分**：较差，必须修改 ❌

### Gradio界面

提供直观的三栏布局Web界面：

- **左侧面板**：API配置、主题输入、章节选择、操作按钮
- **中间内容区**：多标签页显示大纲、状态、章节内容、评审等
- **右侧侧边栏**：章节目录，实时显示创作进度

## 📊 工作流程示例

### 示例：创作一部5章科幻小说

**第一步：创建大纲**
```
输入主题 → 策划者生成5章大纲 → 显示章节目录
```

**第二步：逐章创作**
```

总耗时：约10-20分钟（取决于修改次数）
```

**第三步：导出小说**
```
点击导出 → 生成包含5章的完整小说
耗时：即时
```

## 📝 注意事项

- 确保有稳定的网络连接
- OpenAI API 调用会产生费用，每章约消耗2000-4000 tokens
- 不同模型的效果和成本差异较大：
  - `gpt-4o-mini`: 便宜快速，适合测试，每章约$0.01
  - `gpt-4`: 质量最高，但成本较高，每章约$0.10
- 建议按顺序创作章节，以获得最佳连贯性
- 可以随时中断，下次继续创作剩余章节
- 生成内容仅供参考和娱乐，请合理使用

## 🎓 高级用法

### 非顺序创作

虽然建议按顺序创作，但系统支持任意顺序：

- 先创作第1、3、5章
- 再补充第2、4章
- 后续章节会参考所有已完成章节

### 章节重写

如需重写某章：

- 再次选择该章节号
- 系统会覆盖原有内容
- 评审历史会累积保存

### 大纲调整

如需调整大纲：

- 重新创建大纲会清空所有章节
- 建议先导出已完成内容
