# 📚 AI多智能体小说创作系统（审核循环版）

基于 **LangGraph** 和 **Gradio** 的多智能体协作小说创作应用。本系统使用三个专业AI智能体协同工作，并通过智能审核循环机制，确保作品质量。

## ✨ 特性

- 🎬 **策划者智能体**：构思故事大纲和情节结构
- ✍️ **作家智能体**：根据大纲撰写并润色小说内容（合并了编辑功能）
- 🎭 **评论家智能体**：严格评审作品质量并决定是否通过
- 🔄 **智能审核循环**：评论家不通过时，作家会根据反馈修改作品（最多5次）
- 📊 **完整历史追踪**：记录所有评审过程，可追溯改进历程
- 🌐 **友好的Web界面**：基于Gradio构建的直观用户界面

## 🏗️ 系统架构

本系统采用 LangGraph 构建多智能体工作流，包含条件分支和循环：

```
用户输入主题
    ↓
策划者 (Planner) - 创建故事大纲
    ↓
作家 (Writer) - 撰写并润色小说
    ↓
评论家 (Critic) - 评审并判断
    ↓
   ┌──── 通过审核？────┐
   │                  │
  是                 否
   │                  │
   ↓                  ↓
  结束        作家修改（最多5次）
               │
               └──→ 返回评论家
```

### 工作流程详解

1. **策划阶段**：策划者根据用户主题创建详细大纲
2. **创作阶段**：作家根据大纲撰写小说（首次）
3. **评审阶段**：评论家评分并判断是否通过
   - **评分 ≥ 7分**：通过，结束流程
   - **评分 < 7分**：不通过，返回修改
4. **修改循环**：
   - 作家根据评论家的反馈修改作品
   - 评论家重新评审
   - 重复直到通过或达到5次修改上限
5. **结束条件**：
   - 评论家批准通过
   - 或已修改5次（使用最后一版）

## 🚀 快速开始

### 1. 环境要求

- Python 3.8+
- OpenAI API Key

### 2. 安装依赖

```bash
# 克隆项目
git clone <your-repo-url>
cd test-claude-code

# 创建虚拟环境（推荐）
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# 或 venv\Scripts\activate  # Windows

# 安装依赖
pip install -r requirements.txt
```

### 3. 配置环境变量

复制 `.env.example` 文件并重命名为 `.env`：

```bash
cp .env.example .env
```

编辑 `.env` 文件，填入你的 OpenAI API Key：

```
OPENAI_API_KEY=your_openai_api_key_here
```

### 4. 启动应用

```bash
python app.py
```

应用将在 `http://localhost:7860` 启动。

## 📖 使用说明

1. **输入API配置**
   - 在左侧面板输入你的 OpenAI API Key
   - 选择合适的模型（推荐 `gpt-4o-mini` 或 `gpt-4`）
   - 可选：配置自定义的 API Base URL

2. **输入小说主题**
   - 在"小说主题"文本框中描述你想要的小说
   - 可以参考示例主题获取灵感

3. **开始创作**
   - 点击"开始创作"按钮
   - 等待AI智能体协作完成（时间取决于修改次数）

4. **查看结果**
   - 在右侧标签页中查看各个阶段的产出：
     - 📊 **创作状态**：修改次数、审核结果等信息
     - 📋 **故事大纲**：策划者创建的大纲
     - ✨ **最终作品**：通过审核的最终小说
     - 📝 **当前版本**：作家的最新版本
     - 📜 **评审历史**：所有评审记录和反馈

## 🎯 核心功能

### NovelWritingAgents 类

多智能体系统的核心类，包含：

- `_planner_agent()` - 策划者智能体
- `_writer_agent()` - 作家智能体（包含首次创作和修改逻辑）
- `_critic_agent()` - 评论家智能体（评审并判断是否通过）
- `_should_continue()` - 条件判断函数（决定循环或结束）
- `create_novel()` - 创作小说的主函数
- `stream_create_novel()` - 流式创作（支持实时更新）

### 审核标准

评论家的评分标准：

- **8-10分**：优秀，通过审核 ✅
- **6-7分**：良好，可以通过 ✅
- **4-5分**：一般，需要改进 ❌
- **1-3分**：较差，必须修改 ❌

### Gradio界面

提供直观的Web界面，包括：

- API配置面板

- 分标签页的结果展示（大纲、最终作品、当前版本、评审历史）
- 示例主题快速选择

## 📊 工作流程示例

### 成功案例（一次通过）

```
策划者 → 作家（首次创作）→ 评论家（评分8分，通过）→ 结束
总耗时：约2-3分钟
```

### 修改案例（需要改进）

```
策划者 → 作家（首次）→ 评论家（5分，不通过）
         ↓
      作家（第1次修改）→ 评论家（6分，不通过）
         ↓
      作家（第2次修改）→ 评论家（7分，通过）→ 结束
总耗时：约4-5分钟
```

### 达到上限案例

```
策划者 → 作家 → 评论家（不通过）→ ... 循环5次 ... → 使用最后一版
总耗时：约8-10分钟
```

## 📝 注意事项

- 确保有稳定的网络连接
- OpenAI API 调用会产生费用，请注意使用量
- 不同模型的效果和成本差异较大

  - `gpt-4`: 质量最高，但成本较高
